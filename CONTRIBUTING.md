# Contributing

Contributions are welcome when they strengthen people-centered reasoning without weakening provenance or portability.

## Requirements

1. Explain the product/design decision the contribution improves.
2. Prefer primary, standards, or peer-reviewed sources; label applied guidance and synthesis accurately.
3. Include source title, publisher/author, stable URL or identifier, license when material is adapted, and access date where useful.
4. Keep the main skill concise. Put depth in a directly linked reference.
5. Do not add private course material, student work, copyrighted source copies, credentials, personal data, or UI/UX Pro Max runtime/content.
6. Do not convert heuristics into universal rules or growth outcomes into proxies for wellbeing.
7. Preserve authorship and all upstream notices.

Run `python3 scripts/validate_repo.py` before opening a pull request.
