# Open-access HCI theory ledger

Use this ledger when a task needs theory beyond the compact foundations guide, especially when the user cannot access subscription journals. It favors lawful, authentic copies from publishers, authors, universities, governments, and established repositories. Access was checked 2026-08-29; ACM entries were relabeled on 2026-11-23 because the ACM Digital Library has been free to read since 1 January 2026.

## Evidence and access labels

- **PRIMARY—OPEN:** the original work is openly readable from its publisher, author, institution, or a recognized repository.
- **AUTHOR MANUSCRIPT:** a lawful author- or institution-hosted version of the peer-reviewed work; pagination may differ from the version of record.
- **OPEN SYNTHESIS:** an authoritative open explanation or review. Use it to learn or teach the theory, but cite the original work for historical priority and exact claims.
- **CITATION/ABSTRACT ONLY:** the canonical work is identified, but no dependable lawful full text was confirmed. Do not imply that the full paper was read.

Availability is not a reuse license. Link and synthesize in original words unless the source explicitly grants broader reuse rights. Verify the live license before redistributing source text or figures.

## Retrieval workflow

1. Start with the primary or author-manuscript link above.
2. If it fails, search the exact title in Google Scholar and choose **All versions**; then check the author’s institutional page, CORE, OpenAIRE, OSF, Zenodo, or an institutional repository.
3. Prefer a publisher, author, university, government, or recognized repository over an anonymous mirror or commercial upload platform.
4. Confirm title, authors, venue, year, DOI, and version. Record page numbers from the version actually read.
5. If only an abstract is available, use it only for high-level scope. Use an authoritative open synthesis for explanation and label the provenance explicitly.
6. Never cite a DOI landing page as though it proves a detailed claim that requires the unavailable full text.

## Suggested citation note

For an author manuscript, cite the version of record and add the lawful manuscript URL. For example: `Horvitz, E. (1999). Principles of Mixed-Initiative User Interfaces. CHI '99. https://doi.org/10.1145/302979.303030. Author manuscript: Microsoft Research URL.`
