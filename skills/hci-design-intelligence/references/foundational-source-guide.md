# Foundational HCI source guide

Use this guide when academic provenance, historical context, or the boundary of a model matters. It is a bibliography and interpretation guide, not a substitute for reading the original work. Verify editions and page numbers before quotation.

For broader theory coverage and lawful free-reading routes, use [open-access-theory-ledger.md](open-access-theory-ledger.md). Its access labels distinguish original open works, author manuscripts, open syntheses, and citation-only records.

## Coverage baseline

Use [ACM/IEEE-CS/AAAI CS2023 Human–Computer Interaction](https://csed.acm.org/human-computer-interaction/) as a curriculum coverage check: foundations, interaction design, implementation, user-centered design and testing, new technologies, collaboration, quantitative methods, human factors/security, design-oriented HCI, and immersive systems.

## Core works

| Construct | Foundational source | Responsible use |
|---|---|---|
| Human performance models, GOMS | Card, Moran, and Newell, *The Psychology of Human-Computer Interaction* (1983) | Skilled routine behavior under explicit assumptions; not emotion, discovery, or collaboration |
| Target acquisition | Fitts, “The Information Capacity of the Human Motor System in Controlling the Amplitude of Movement” (1954), [DOI 10.1037/h0055392](https://doi.org/10.1037/h0055392) | Model a defined pointing task, device, target, and distance |
| Choice reaction | Hick, “On the Rate of Gain of Information” (1952), and Hyman, “Stimulus Information as a Determinant of Reaction Time” (1953), [DOI 10.1037/h0056940](https://doi.org/10.1037/h0056940) | Do not translate controlled choice-reaction findings into “always show fewer options” |
| Direct manipulation | Shneiderman, “Direct Manipulation: A Step Beyond Programming Languages” (1983) | Examine continuous representation, rapid action, feedback, reversibility, and user skill |
| Heuristic evaluation | Nielsen and Molich, “Heuristic Evaluation of User Interfaces” (CHI 1990) | Inspection method; findings remain hypotheses about user impact until validated |
| Affordances and perception | Gibson, *The Ecological Approach to Visual Perception* (1979) | Distinguish ecological affordance from later interface shorthand |
| Conceptual models, action cycle, signifiers | Norman, *The Design of Everyday Things* | Use the edition named by the task and distinguish affordances from perceivable cues |
| Situated action | Suchman, *Plans and Situated Actions* | Treat plans as resources used in local activity, not complete scripts for behavior |
| Distributed cognition | Hutchins, *Cognition in the Wild* | Analyze people, artifacts, representations, environment, and coordination together |
| Cognitive dimensions | Green and Petre, “Usability Analysis of Visual Programming Environments: A Cognitive Dimensions Framework” (1996), [DOI 10.1006/jvlc.1996.0009](https://doi.org/10.1006/jvlc.1996.0009) | Use the vocabulary to inspect representational tradeoffs, not as a universal scorecard |
| Usability in context | ISO 9241-11 | Specify users, goals, context, effectiveness, efficiency, and satisfaction |
| Human-centered lifecycle | ISO 9241-210 | Apply iterative context, requirements, design, and evaluation activities with user involvement |

## Evidence rules

- A classic source can establish a construct or model; it does not prove a current interface causes the predicted effect.
- Prefer the original experiment or peer-reviewed paper for precise empirical claims. Use textbooks and practitioner sites for explanation and synthesis.
- State population, apparatus, task, measures, and boundary conditions when transferring a quantitative model.
- Treat later replication, critique, or extension as part of the evidence—not as an attack on the foundational source.
- Do not copy copyrighted chapters into the skill. Store an original synthesis, citation, edition, and narrow locator.
