# Coursework synthesis: Visual Communication

Public-safe original synthesis derived from user-supplied graduate coursework. It does not reproduce readings, assignments, rubrics, private examples, or participant data. Treat it as a course-informed lens, not as independent empirical authority.

## Use this reference when

Evaluating or creating visual hierarchy, typography, composition, motion, or data visualization.

## Working model

- Visual form should clarify content, relationship, sequence, emphasis, and action; decoration is not a substitute for meaning.
- Begin with audience, purpose, medium, constraints, content structure, and desired interpretation.
- Iterate through divergent studies before converging. Critique the relationship between intent and effect, not personal taste alone.
- Composition coordinates hierarchy, scale, contrast, proximity, alignment, rhythm, balance, figure-ground, and whitespace.
- Typography carries language, hierarchy, tone, pace, and accessibility. Test the actual content, sizes, line lengths, weights, scripts, states, and environments.
- Motion should communicate change, causality, continuity, focus, or feedback while respecting reduced-motion needs.

## Data visualization

Define the question, audience, data provenance, variables, uncertainty, comparison, and intended decision before choosing a chart. Seek integrity, usefulness, and legibility; never trade truthful representation for visual drama.

Check scales, baselines, aggregation, missing data, uncertainty, color meaning, labels, annotations, ordering, density, and accessibility. Provide the underlying values or an accessible alternative when interaction or vision is required.

## Critique prompts

1. What should be noticed, understood, compared, or done first?
2. Does hierarchy match the intended task and reading order?
3. Which visual choices carry meaning, and which merely add noise?
4. Does the design remain legible across content, device, zoom, contrast, motion, and localization conditions?
5. What evidence supports the interpretation, and what should be tested with people?
