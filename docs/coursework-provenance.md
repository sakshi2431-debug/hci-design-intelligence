# Coursework provenance and publication boundary

The repository includes nine original reference modules synthesized from graduate HCI and design coursework supplied privately by the repository author:

- Advanced Usability
- Conversational UX
- Design Systems
- Digital Accessibility
- Information Architecture
- Interaction Design Project Practice
- Service Design
- Usability Testing
- Visual Communication

## What is included

The modules preserve durable conceptual lenses, decision prompts, method distinctions, and practical guardrails that improve product reasoning. They were rewritten as compact, model-agnostic guidance and are licensed as original repository prose under CC BY 4.0.

## What is not included

The repository does not redistribute course archives, slides, readings, professors' materials, assignment text, rubrics, student submissions, participant data, private client examples, institutional credentials, or paywalled works. The synthesis does not imply endorsement by any instructor, institution, author, or publisher.

## How to use this layer

Coursework synthesis is a contextual and pedagogical source. It may shape questions, frameworks, and design judgment, but it is not automatically an external standard or empirical finding. Consequential claims should be checked against the repository's standards, primary research, direct project evidence, or authoritative applied guidance.

When citing an idea externally, cite the original standard or publication when available rather than this synthesis. When the original source is unknown or unavailable, label the point as course-derived guidance or an inference.
